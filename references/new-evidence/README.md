# Future evidence

This folder is intentionally unpopulated with new hardware research. Add dated manufacturer manuals/datasheets, exact supplier quotes, connector drawings, CAD, experiment records, and concise source notes as design work proceeds. Link them from the relevant research note, BOM, interface, or decision. Preserve URL, checked date, document/revision/section, exact hardware variant, and whether a claim is published, calculated, assumed, or measured. Do not save credentials or private access tokens.
