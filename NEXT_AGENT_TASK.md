# Task brief for the next design agent

Complete the installed design and purchasing package for **PW-APPROACH-01**, selected in [SRC-034](references/new-evidence/2026-11-16-final-approach/PaveWatch_Approach_Final.docx). ## Configuration and scope

- Custom 500 mm hybrid X frame: CNC carbon-fiber center plates/tube arms; PA6-CF clamps, landing fittings, sensor carrier, and electronics mounts. Holybro X500 v2 CAD is a dimensional reference.
- MicoAir H743v2-AIO-35A with four integrated 35 A ESC channels; PX4 1.16.0, exact MicoAir743v2 target as stated in the source; QGroundControl; M10G GNSS/compass.
- Four SunnySky X2216 880 KV motors, Master Airscrew MR 10 × 4.5-inch props, 4S 14.8 V nominal 5,200 mAh LiPo. RadioMaster Pocket 2.4 GHz ELRS and RP1 V2 receiver; separate laptop MAVLink telemetry.
- Supplied picoScan150 Pro, reported received and streaming over Ethernet; Raspberry Pi 4 Model B; standard Camera Module 3 over CSI; SanDisk Extreme 128 GB survey card in a USB 3 reader, separate OS card; Python acquisition on the Raspberry Pi OS path, exact versions to freeze.
- Separate protected LiDAR and recorder power branches; rigid removable sensor plate; ventilated PETG/ASA electronics cover and cable guides; non-magnetic GNSS/compass mast.
- Post-flight processing with independent geometry/image branches; local workstation versus cloud execution undecided. Hosted reporting with PostgreSQL/PostGIS, cloud evidence files, login/dashboard/PDF is primary. Local SQLite app is a fallback; learned RGB/depth fusion remains optional.

Design the whole operating system, including harnesses, mounting, cooling, ground equipment, fixtures, transfer/backup, and recurring services. Preserve the six subsystem owners. Keep older X500/H7/Orange Pi, S500/Pixhawk, and F450/SpeedyBee alternatives outside the active BOM.
